Task 2 - Professional Calculator

Project Overview

A professional GUI-based calculator developed using Python and Tkinter.

Technologies Used

- Python
- Tkinter

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Percentage (%)
- Square Root
- Square
- Decimal and Brackets
- Clear and Backspace
- Keyboard Support
- Calculation History
- Error Handling

How to Run

1. Install Python.
2. Download "calculator.py".
3. Open the terminal in the project folder.
4. Run:

python calculator.py
